# Setup Guide

## Requirements

- Python 3.9+
- pip

## Install

```bash
git clone https://github.com/robinnnn0101-ship-it/VexloreQuantumProofchain.git
cd VexloreQuantumProofchain
pip install -r requirements.txt
```

## Run

```bash
python3 vexlore_chain.py
```

## Docker

```bash
docker build -t vexlore .
docker run -it -p 5000:5000 vexlore
```

See README for more.
